## Changes

- Reuse the existing tolerant numeric conversion helpers for optional quote and depth fields. A missing open-interest value becomes the common API's unavailable/default zero while valid LTP, previous close and sibling prices survive. No new retry, request, batching limit or concurrency bypass is introduced. Missing bid/ask returns zero/unavailable, never LTP as a made-up spread.
- On a failed instrument/interval switch, rebuild an empty chart for the requested metadata if the existing canvas belongs to a different data key. The old chart and its overlays are destroyed through the existing lifecycle. The correct toolbar metadata is published, retry rebuilds with authoritative bars, and a same-instrument cached chart remains intact. Failed history still blocks chart order actions through the existing data-unavailable guard.
- Use the SDK's public `fetchImpl` extension to retain the local server's history explanation. Known Kotak history capability refusals say live quotes and supported trading remain available and do not offer repeated retry as a remedy. Generic failures retain their retry control. No SDK package, order API, broker credential, execution mode or security exposure changes.
- MCX/CDS historical candles remain unavailable from Kotak. No fake candles, local reconstruction of past ticks, or silent FYERS-to-Kotak data fallback is introduced. A historical provider supporting the exchange is required for those charts.
