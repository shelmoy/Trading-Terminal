## New changes since yesterday's prepared review

- **Expired-login protection:** WebSocket helper routes and market Socket.IO authorization now require a current session; before03:00IST, validity compares against the most recent rollover rather than accepting arbitrarily old cookies. This closes the expired-cookie API-key disclosure path described by upstream. Disconnect still cleans rooms without revoking another device's broker token. It applies to Kotak and FYERS. The prepared integration includes this patch; no compromise is asserted. [Official security fix](https://github.com/marketcalls/openalgo/commit/e2bdd061e).
- **FYERS live-feed correctness:** each HSM incremental update is published whole; bid/ask/volume-only changes are no longer lost behind LTP deduplication. Change/percent derive from previous close; depth does not invent midpoint LTP, and index depth is not fabricated. Custom selective unsubscribe, callback ownership and index fan-out are retained. [Official FYERS fix](https://github.com/marketcalls/openalgo/commit/8d2bece9d).
- **SMTP security:** verify certificate and hostname before SMTP login/reset email; remove credential-bearing SMTP debug transcripts. Private/self-signed/IP-only mail setups may now need a valid matching certificate/hostname; do not disable verification to work around this. No real email was sent. [Official SMTP fix](https://github.com/marketcalls/openalgo/commit/af5d5f2cc).
- **Tornado6.6** replaces6.5.10 for upstream's security advisories. It is a Jupyter dependency, not OpenAlgo's web server. Yesterday's prepared dnspython2.9.0/msgpack1.2.3, XTS/Samco log redaction, Groww reconnect and Angel trigger mapping are also included. Their earlier review remains preserved.
- **Sahi broker plugin/UI selection** is added. No Sahi credentials were configured, master contracts downloaded or account connected. REST/order mapping tests passed with mocked transports; no Sahi account was connected. [Official Sahi addition](https://github.com/marketcalls/openalgo/commit/a1adec367).
- No chart SDK upgrade, Renko/indicator mathematics, Scalper915, live P&L arithmetic, margin or Exit All redesign. Native themes, V4 Trading history/persistence recovery, Gaussian blue/maroon, broker routing and all other customizations remain. No database migration is required by the release. The cancelled chart-trading feature remains cancelled.
