# Android retained chart workspace 0.2.2

Ordinary minimize/resume retains native quotes, subscriptions, chart WebViews
and selections instead of clearing and reloading them. Foreground checks
identity, broker, credential and Live/Analyze authority; expiry/revocation or
changes invalidate scoped state and require normal authentication. Lost native
feeds can recover after validation without reconnecting healthy streams.
The secure biometric modal retains underlying UI; cold process death remains
a fresh safe start. Android can throttle/kill background processes: continuous
networking and missing ticks are not guaranteed. Resize/focus redraw uses the
existing chart hooks; physical OnePlus ghosting acceptance remains pending.

Both Trading and Scalper expose the exact existing indicator picker/catalogue,
option chain and chart books. Compact Sell/lots/Buy controls open the existing
confirmation ticket; they never place on opening. Chain and chart tickets use
the same guarded terminal feed, including replay/data/mode refusals. Native
messaging only carries presentation and explicit contract selection, never
order commands. External chain/book selection uses a clearly named contract
view in Scalper, with Back to strikes; it does not pretend the old CE/PE/expiry
selectors describe the newly selected instrument. Existing broker API and
confirmation behavior are retained. This is an original OpenAlgo workflow
informed by Sahi/Kite, not an exact clone or unsupported attached protection.

Windows validation: 29 native JVM tests (warm-resume retention and revocation),
86 focused web/ChartPane/Renko tests (ticket lots, no auto-place, replay refusal,
shared chain feed), TypeScript, temporary production build, signed Android
release/lint, eight real SDK Chrome fixtures with fake transports in both
themes/orientations/brokers, including indicator/chain/books opening. No actual
broker test order, cancel, close or mode change. Source/cache/gesture lifecycle
review is static plus isolated checks, not measured background uptime or fill
timing. Physical installation/resume/lock/network-switch acceptance is pending.

SDK 2.6.9, Renko/custom studies/icons, history fixes, Gaussian styling, P&L/margin
and ExitAll safeguards are preserved. Desktop default layout is unchanged.
Activation is frontend-only, retains old chunks and exact canonical bytes,
requires no backend restart/schema/env/exposure change. Separate Android/web
repositories and private recovery snapshots remain intact.
